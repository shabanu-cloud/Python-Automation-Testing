# Python Automation Testing — Companion Code

Companion source code for the book **Python Automation Testing: The Practical Professional Handbook** by **Sharmila S**.

Learn PyTest, Selenium, Playwright, API testing and CI with code that is proven to run:
**76 automated tests** and **7 example scripts**, all passing.

---

## 📥 Download

1. Click **[python-automation-handbook-code.zip](python-automation-handbook-code.zip)**
2. Click **Download raw file** (top right)
3. Unzip it

## ▶️ Run it

**macOS / Linux**

```bash
./run_tests.sh
```

**Windows PowerShell**

```powershell
.\run_tests.ps1
```

Expected result: **76 passed** and **7/7 example scripts passed**.

Step-by-step setup instructions are in `README.md` inside the ZIP (and in Chapter 3 of the book).

## 📂 What's inside

| Folder | Contents |
|---|---|
| `demo/` | Checkout practice app, frames demo and a local JSON API (runs offline) |
| `pages/` | Playwright and Selenium page objects |
| `tests/` | 76 verified tests across 11 modules |
| `src/` | Helpers: money maths, data loader, API client, PDF tools |
| `examples/` | 7 standalone scripts from the book |
| `exercises/` | Starter files for Chapter 15 |
| `test_data/` | JSON test cases |
| `.github/workflows/` | GitHub Actions CI pipeline |

## 🧰 Requirements

- Python 3.10 – 3.13
- Google Chrome or Chromium
- No internet accounts or public test websites needed
